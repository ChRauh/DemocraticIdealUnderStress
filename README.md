# *Replication archive:* Democratic Ideal Under Stress
    
This repository provides all data and scripts needed for replicating the results reported in:    
    
> Rauh, Christian, Heiko Giebler, Jan-Paul Heisig, Johannes Gerschewski, and Jianghong Li (2026) "The democratic ideal under stress:  Citizen commitment to democratic rights and procedures in challenging times", *European Journal of Political Research (EJPR)*: forthcoming.    
    
    
    
## Input data

All analyses are based on the second survey wave of the project "Regime and cultural determinants of the acceptance of political decisions in times of crisis (DAPEK)", which is publicly documented and available via GESIS (DOI: [10.7802/2447](https://doi.org/10.7802/2447)). When using this data in your own work, please cite:     
    
> Giebler, H., Rauh, C., Heisig, J. P., Carstens, A., Li, J., & Gerschewski, J. (2022). Regime and cultural determinants of the acceptance of political decisions in times of crisis (DAPEK) (Version 1.0.0) [Data set]. WZB - Berlin Social Science Center. https://doi.org/10.7802/2447    
    
   
   
## Repository structure    
    
The repository is organised as an RStudio project - start from `DemocraticIdealUnderStress.Rproj` to have all relative paths working right away. All analyses have been run in R version 4.2.2 (2022-10-31 ucrt) -- "Innocent and Trusting". Additional R packages used are indicated on top of each individual script with version number and library source.    

### Folders    

- The **root** holds all analysis scripts    
- Folder **./Data** holds all data input - including the original DAPEK survey data as well as contextual information from the World Value Survey, V-Dem, and the Oxford COVID-19 Government Response Tracker. When using these data, please refer to the original sources as indicated in the main article.    
- Folder **./Output** holds all figures and tables generated by the analysis scripts as reported in the main text.    
    
    
### Scripts
- **`0_CountrySample.R`** locates our country sample in the broader universe of countries regarding democratic maturity, cultural orientations and COVID-19 restrictions (as reported in **Section 3 of the main text** and **Appendix A.2**)    
- **`1_PrepareBackgroundData.R`** scrutinizes, cleans and labels the raw survey data provided by IPSOS focusing on the questionnaire items (experimental data are prepared in the respective scripts for study 1 & 2)    
- **`2_Study1.R`** replicates all analyses regarding the conjoint experiment on democratic rights restrictions, generating the outputs reported in **Section 4**, partially **Section 6**, and **appendix A.4** of the main text.    
- **`3_Study2.R`** replicates all analyses regarding the best-worst scaling / framing experiment on prefernces for democratic procedures, generating the outputs reported in in **Section 5**, partially **Section 6**, and **appendix A.5** of the main text. 
     
     
## Preregistration

The analyses conducted here have been publicly pre-registered via OSF prior to data access (DOI: [10.17605/OSF.IO/43FGX](http://doi.org/10.17605/OSF.IO/43FGX)). Deviations from the pre-registration are discussed throughout the main text and summarized in appendix A.1.
